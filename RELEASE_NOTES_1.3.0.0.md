Release 1.3.0.0 - Cross-platform publishing

Summary:
- Updated the Windows and cross-platform client version metadata to 1.3.0.0.
- Added self-contained single-file publishing targets for common Windows, Linux, and macOS architectures.
- Added Linux musl targets for x64 and ARM64 environments.

Published target folders:
- Windows: windows-x86, windows-x64, windows-arm64
- Linux: linux-x86, linux-arm, linux-arm64, linux-musl-x64, linux-musl-arm64
- macOS: macos-x64, macos-arm64

The existing application behavior, networking protocol, and user-facing features are unchanged.
